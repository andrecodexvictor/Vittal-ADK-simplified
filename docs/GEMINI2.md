# Projeto: ADK Interno para Agentes de WhatsApp/CRM (Simplificado)

Este repositório define o kit de desenvolvimento de agentes (ADK) interno simplificado.

Objetivos principais:
- Padronizar a criação de agentes de WhatsApp/CRM.
- Reduzir a complexidade e número de camadas de arquitetura.
- Carregar dinamicamente o contexto e variáveis de cada pasta de agente.
- Utilizar arquivos de teste TypeScript normais e executá-los com `bun test` diretamente.

Estrutura de documentação:
- `docs/specs/ADK-SPEC.md` – especificação do ADK.
- `docs/specs/AGENT-SPEC-TEMPLATE.md` – template de especificação por agente.
- `docs/specs/PROCESS.md` – fluxo de trabalho simplificado.
