# Conversational Examples - Clinica Bela Pele

- **User**: "Qual o horário de funcionamento de vocês?"

- **User**: "Vocês fazem aplicação de botox?"
- **Agent**: "Sim! Realizamos aplicação de toxina botulínica (botox) na clínica. Gostaria de entender melhor para qual região você tem interesse, ou quer que eu te transfira para a recepção para agendar uma avaliação?"

## Example 3: Attendant Handoff
- **User**: "Quero agendar uma consulta com o médico."
